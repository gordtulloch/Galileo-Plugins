# MobileConnect

Lets you watch and run this observatory from the Galileo MobileConnect app on a tablet or phone on your own network. The app operates the observatory; it can't change its configuration, which stays on this computer.

MobileConnect belongs on the Master computer. On a computer that is a NodeConnect spoke it stays switched off.

## Waiting for approval

Apps asking to pair. Each shows a six-digit code: check it's the same code the app shows before approving. If you didn't just ask from an app, refuse it.

## Approve as Viewer

Pairs the selected app so that it can watch but not operate. This is the safer choice, and you can promote it later.

## Approve as Operator

Pairs the selected app so that it can operate this observatory: slew, expose, focus, run sessions and use the emergency actions. It still has to take a Pier's lease before most operations, and the safety rules apply as they do on this computer.

## Refuse

Turns the selected request away. The app is told.

## Paired apps

The apps paired with this computer, and each one's role.

## Make Viewer

Stops the selected app operating anything. If it held a lease, the lease is released.

## Make Operator

Lets the selected app operate this observatory.

## Revoke

Removes the selected app's access at once: its connection closes, its lease is released and it has to pair again. Do this for a lost device.
