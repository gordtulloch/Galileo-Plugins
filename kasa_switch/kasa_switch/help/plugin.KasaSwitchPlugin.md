# Kasa switches

Controls TP-Link Kasa smart plugs and power strips (for example the HS300) on your network. It appears on **Equipment > Switches**. Each device found gets a box listing its outlets. The Kasa app's **Third-Party Compatibility** setting must be on for the device, or it refuses connections from Galileo.

## Scan for KASA switches

Broadcasts on every network adapter of this computer for about three seconds and adds each Kasa device that answers as a box below. Devices already listed are not added twice. If nothing answers, check that the device is on this network and that Third-Party Compatibility is on in the Kasa app, or use **Add by IP…**.

## Add by IP…

Adds a device by hand when the scan cannot find it, for example one on another subnet. **Host / IP** is the device's address or name; **Label** is an optional display name that defaults to the host.

## On

Switches this outlet on. The button is filled green while the outlet is on.

## Off

Switches this outlet off. The button is filled red while the outlet is off.

## Remove

Forgets this device. Scan again to find it.
